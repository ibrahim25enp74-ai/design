# References

Save the images you like (or dislike) in this folder. Put "no" at the start of a disliked image's name, for example `no-gradient-post.jpg`. The taste skill reads these images and turns them into concrete preferences in `../preferences.md`.

ضع هنا الصور التي تعجبك (أو التي لا تعجبك، وابدأ اسمها بـ no). سيقرأها الـ skill ويحوّلها إلى تفضيلات واضحة في ملف preferences.md.
